# Git Starter

Two buttons for GitStudio's empty **Changes** view (needs the GitStudio fork with *extension actions*):

- **New Repo** — creates a Git repository in the open folder (asks first), or in a folder you choose, then opens it. If the folder holds a TIA Portal project and TIA Portal Tools is installed, it offers its Git settings.
- **Clone** — shown when the clipboard holds a repository link. Opens a form: link, target folder and name, all branches or one branch (list read from the server), shallow depth, submodules, no checkout, and what to open afterwards. An empty open folder is cloned into directly.

Both are also in the Command Palette (Git Starter: New Repository… / Clone Repository…).
